# Lineage M metric-break audit

## What changed

The NCSOFT 2Q26 presentation states that royalties are integrated into IP revenue. Its mobile chart reports a restated/new-scope five-quarter Lineage M window. The earlier presentations use a legacy mobile-title chart without that integrated-royalty statement.

## Versions

- `md_nc_lineage_m_legacy_v1`: 2024Q3–2025Q4, six quarters.
- `md_nc_lineage_m_royalty_v2`: 2025Q2–2026Q2, five quarters.

## Overlap

The versions overlap in 2025Q2, 2025Q3, and 2025Q4:

| Quarter | Legacy v1 (KRW million) | Royalty-integrated v2 (KRW million) |
| --- | ---: | ---: |
| 2025Q2 | 121,111 | 127,908 |
| 2025Q3 | 105,339 | 118,794 |
| 2025Q4 | 93,817 | 104,531 |

These values are not alternatives to select from. They document different publisher metric definitions.

## Comparison rule

Direct level or QoQ comparison across v1 and v2 is forbidden. The first v2 change-feature row is null with reason `METRIC_VERSION_BREAK`. Subsequent v2 changes may be calculated only within v2.
