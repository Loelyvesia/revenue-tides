# Event and causality policy

Eligible official events include game/platform launches, expansions, major versions, anniversaries, collaborations, major content updates, and other large officially documented product or monetization events.

Each record requires entity, official source, date/range, date precision, fiscal period, and applicable platform/region scope. The primary association window is the same fiscal quarter. Previous/next-quarter context is optional and descriptive only. Multiple events in one quarter are all retained.

Event presence establishes `TEMPORAL_CONTEXT`, not causality. Permitted wording notes that an event occurred in the same quarter, that a series changed during that quarter, or that a named issuer attributed performance to the event.

Independent claims that an event caused a revenue change are forbidden without a separately approved causal design. Issuer explanations remain `ATTRIBUTED_CLAIM` and name the source.
