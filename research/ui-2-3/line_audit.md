# UI 2.3 Line Audit

Audit scope: Hero, Measurement, Quarter Prism, F1, F2, F4 and Archive. “Construction line” means a baseline, axis tick, full frame, divider, connector, or default node—not the thin top waterline used to preserve quarterly precision.

| Scene | UI 2.2 construction | UI 2.3 result |
|---|---:|---:|
| Hero | 9 ridges, all-quarter nodes, ruler line, transition strokes | 9 very light waterlines; no nodes, ruler line or transition strokes |
| Measurement | baseline, version seam line, event tick, reading/card edges | no baseline; seam is a blurred field; event is a local halo; readout floats |
| Prism direct | baseline, all-quarter ticks/nodes, four aperture rails, hard glass frame | no axis/ticks/rails/frame; one selected bead inside a gradient field |
| Prism overlap | two lanes plus connector-like labels and double seam lines | second definition exists only through a soft mask; seam is a disturbance zone; no connector |
| F1 | large framed stage, central measurement bracket, row divider | two current bodies, open spacing, no bracket or frame |
| F2 | baseline, full-height event line, eight nodes | no baseline/event line; one critical crest bead and a local event halo |
| F4 | baseline, eight ticks, eight nodes, five annotation leaders | no baseline/ticks/leaders; four evidence-critical beads only |
| Archive | nine row separators plus one full-height column divider | whitespace and field response only; no row/column dividers |

Estimated construction primitives across the audited desktop scenes fell from more than 70 to fewer than 20. The remaining lines are precision waterlines, uncertainty whiskers, focus outlines, or source controls.

The first visual layer is now area and color mass. Lines are subordinate.
