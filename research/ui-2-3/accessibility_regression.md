# Accessibility Regression

- Keyboard quarter selection remains available through Left/Right keys and the quarter ruler.
- Native series select and source controls remain keyboard accessible.
- Exact values, units, reporting versions, evidence mode, source links and non-causal event language remain in text.
- Removing axes and default nodes does not remove any numeric information.
- Derived uncertainty still uses geometry/pattern plus text, not color alone.
- Reporting-version overlap still uses labels and separate observations, not color alone.
- Reduced motion disables transitions, reveals and surface reshaping while retaining the complete static composition.
- Focus outlines remain visible.
- Chrome, Edge and Firefox console/network checks passed.
