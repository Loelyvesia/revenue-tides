# GitHub reference implementation

## Status

`IMPLEMENTED / ORIGINAL REVENUE TIDES DESIGN`

The repositories below were studied before implementation. No code, data, React component, R implementation, or project-specific visual was copied. Revenue Tides remains a Vue application with its own SVG geometry and frozen public Web Data.

| Reference | Pattern learned | Revenue Tides implementation | Deliberate boundary |
|---|---|---|---|
| [hrbrmstr/streamgraph](https://github.com/hrbrmstr/streamgraph) | A centered field can make time read as volume and rhythm rather than a bundle of lines. | Hero uses nine translucent, within-series-normalized ribbons around a shared visual field. | No cross-company actual-value stack; no R dependency; no implied additive total. |
| [plouc/nivo](https://github.com/plouc/nivo) | Layered fills, gradients, patterns, transitions, and theme roles can coexist with readable anchors. | Tidal Band combines a filled ribbon, luminous ridge, real-quarter nodes, semantic gradient roles, and non-color version/uncertainty encodings. | No React/Nivo runtime and no general chart framework. |
| [galiat/State-of-the-Union-Viz](https://github.com/galiat/State-of-the-Union-Viz) | A dominant stream and a synchronized time scrub can make temporal focus the interaction itself. | Quarter Prism synchronizes aperture, reading output, and bottom ruler; interaction lands only on canonical quarters. | No interpolation-derived tooltip and no intermediate pseudo-observation. |

## Patterns adopted

1. **Normalized central-axis tide field.** Hero geometry is normalized inside each series; it never compares or stacks absolute company revenue.
2. **Filled tide + precise ridge + visible anchors.** The band supplies volume, while the ridge and quarter nodes preserve exact reading locations.
3. **Synchronized aperture scrub.** Quarter selection updates geometry, reading output, evidence, and ruler as one instrument.
4. **Layered material states.** Gradient, pattern, local glow, blur, and opacity communicate data state rather than generic decoration.
5. **Evidence-bearing staged motion.** Reveal, reshape, and pulse direct attention but do not create observations; reduced-motion shows the final evidence immediately.

## Patterns rejected

- Actual-value stream stacking across publishers or currencies.
- Reading values from visually smoothed segments between quarter anchors.
- Whole-page glassmorphism, neon, particle fields, Three.js, or video backgrounds.
- Pixel-art/dither UI treatment.
- Event-to-revenue connectors or causal animation.
- React/Nivo/D3 runtime adoption; the existing Vue + SVG stack was sufficient.

## Implementation ownership

All final SVG paths are generated by `src/utils/tidalGeometry.ts` from existing canonical observations. Catmull–Rom-to-Bézier conversion is presentational geometry only. Quarter nodes, values, versions, uncertainty intervals, evidence classes, events, claims, and sources remain those in frozen Web Data.
