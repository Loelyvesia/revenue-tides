# Project Timeline

- **Phase A — Data Gate:** Tested public Sensor Tower, AppMagic, official publisher, event, and Steam/PC source feasibility; concluded that the original public monthly amount-first concept required narrowing.
- **Phase A.1 — Public Release Source Resolution:** Identified official listed-company disclosures as the strongest reproducible backbone and pivoted to publisher-defined fiscal-quarter metrics.
- **Phase B — Controlled Pilot:** Built 41 observations across five series, retained official evidence, and validated metric breaks, derivation, identity, events, and provenance.
- **Phase C — Method / Scope Freeze:** Froze the research object, evidence classes, corpus rules, metric-version, missingness, comparability, derivation, causality, and public-release contracts.
- **Phase D — Curated Corpus:** Constructed 9 series, 75 observations, 26 events, and 3 issuer claims from 4 companies without forcing a weaker tenth series.
- **Phase E — Data Quality:** Reconciled the observation grid, corrected three generated-data defects, revalidated all derived values and uncertainty, and produced a findings-ready layer.
- **Phase F — Evidence-Bounded Findings:** Evaluated 19 candidates, promoted and froze 6 Findings, and selected F1/F2/F4 as headlines.
- **Phase G — Web Data Productization:** Built a 16-file, 182,030-byte public-safe JSON layer with stable references, version breaks, bounds, claims, events, sources, and deterministic hashes.
- **Phase H — IA / Visual / Signature Interaction:** Defined Tidal Ledger and Quarter Prism, seven narrative sections, responsive/accessibility behavior, and state prototypes.
- **Phase I — Frontend Implementation:** Built the static Vue 3 + TypeScript + Vite experience and verified 62 frontend tests and Phase G-only data consumption.
- **Phase J — Final Browser QA:** Passed Chrome, Edge, and Firefox checks, six responsive viewports, accessibility-tree review, performance audit, and root/subdirectory hosting.
- **Phase K — Final Audit / Freeze:** Completed competition materials, final semantic and language audits, release smoke, reproducibility documents, file inventory, hashes, and release freeze.
