# UI 2.2 accessibility regression

- Native select, button, details, and link controls remain keyboard-operable.
- Skip link, focus-visible outline, live reading output, arrow-key quarter navigation, and 44 px control policy remain present.
- Reduced-motion rules still disable path drawing, morph transitions, pulses, and animated row changes.
- Direct/derived evidence, version overlap, and uncertainty are not encoded by color alone.
- Naturalized copy did not remove hidden labels required by prior Phase I contracts.
- 390×844 and 320×700 have no page-level horizontal overflow in Chrome and Edge.

Automated regression: frontend 62/62, Phase I 100/100, Phase J 102/102. No formal WCAG certification or live screen-reader certification is claimed.
