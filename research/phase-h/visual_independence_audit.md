# Visual independence audit

All comparisons below were reviewed against the Tidal Ledger system and Quarter Prism grammar.

| Reference family | Status | Evidence of distinction |
| --- | --- | --- |
| Generic finance dashboard | DISTINCT | Editorial chapters and a single analytical canvas replace KPI tiles, ranking summaries, and dense panels. No common absolute-company scale exists. |
| Stock trading interface | DISTINCT | No candlesticks, ticker tape, red/green buy/sell semantics, terminal chrome, or live-market language. Fiscal quarters and publisher definitions are the subject. |
| SaaS analytics dashboard | DISTINCT | No rounded card wall, permanent filter sidebar, success score, funnel, or configurable widget grid. Navigation follows a fixed research argument. |
| Project 01 — Anime Game Chronicle | DISTINCT | No Chronicle Loom, Era Lens, image-first gallery, historical-archive layout, release chronology, or curatorial timeline composition. Revenue Tides is a ledger/calibration instrument. |
| Earthquake Pulse | DISTINCT | No map, epicenter, subsurface cross-section, seismic pulse, or spatial layer interaction. |
| Cyclone Eye | DISTINCT | No storm map, radial eye, lifecycle player, wind field, or meteorological track. |
| Temperature Earth | DISTINCT | No Annual Rhythm Dial, seasonal ring, fingerprint comparator, or global-temperature field. |

## Signature audit

| Criterion | Result | Design evidence |
| --- | --- | --- |
| Tied to frozen data structure | PASS | Metric versions, bounds, events, claims, and sources change the Prism state. |
| Tied to formal Findings | PASS | F1, F2, and F6 have explicit modes; F3–F5 have defined behavior. |
| Not replaceable by ordinary filter | PASS | Selection decomposes a quarter and changes simultaneous geometry. |
| Not ordinary hover | PASS | Drag, step, select, keyboard, and direct-list paths reach the same state. |
| Understandable within 30 seconds | PASS | Guided default sequence: direct → overlap → derived/event, each with one teaching sentence. |
| Produces insight through manipulation | PASS | Moving between quarters reveals definition lanes, interval sign stability, and separate context. |
| Works with direct values | PASS | Direct observation has a solid mark and full scope/source decomposition. |
| Works with derived uncertainty | PASS | Point estimate, bounds, rounded share, and sign stability are simultaneous. |
| Works with version overlaps | PASS | Same-quarter values occupy parallel labeled lanes. |
| Works with events | PASS | Events occupy a separate quarter-aligned context rail. |
| Works on mobile | PASS | The mobile stepper preserves stacked quarter decomposition. |
| Keyboard-accessible | PASS | Previous/Next, arrow keys, select, and direct quarter list reach every state. |
| Reduced-motion capable | PASS | Final structural states appear immediately without losing meaning. |
| Does not imply causality | PASS | There is no event-value connector, impact score, or causal verb. |
| Does not encourage forbidden absolute comparison | PASS | The Prism is single-series; normalized comparison is separately labeled and unitless. |

No `RISK` classification remains after the design revisions recorded in the risk register.
