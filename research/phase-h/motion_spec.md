# Motion specification

## Principles

Motion explains measurement, calibration, transition, and decomposition. It never decorates empty space, loops, or substitutes for labels.

| Motion | Duration | Easing intent | Meaning |
| --- | --- | --- | --- |
| Focus/press response | 120–160 ms | immediate, decelerating | Confirms control input |
| Quarter snap | 160–200 ms | precise ease-out | Moves to one discrete fiscal quarter |
| Evidence pane update | 250–320 ms | short cross-position transition; no fade-only change | Reorders the decomposition |
| Version-lane separation | 400–520 ms | measured ease-in-out | Reveals simultaneous definitions |
| Uncertainty interval extension | 350–500 ms | linear-to-ease-out | Exposes compatible bounds |
| Event rail entrance | 250–350 ms | vertical ease-out | Adds separate temporal context |
| Full signature guided decomposition | 500–650 ms maximum | staged but non-blocking | Teaches number construction |

No initial auto-play is required. No water animation, parallax, particle, glow pulse, ambient loop, or carousel exists.

## Reduced motion

When reduced motion is requested, all states update in one frame. The structural seam, parallel lanes, whiskers, labels, and event rail remain fully visible. Comprehension and keyboard order do not change.

## Interruption and input

New quarter input cancels the prior transition and resolves to the latest selected state. Drag previews do not continuously announce. The live region announces only the snapped result.
