# 设计说明

《付费潮汐》的视觉不是给财报数字套上一层装饰，而是把“如何测量”变成画面的一部分。

九条序列以有厚度的潮位带呈现。每个节点仍然对应真实季度；带状曲线只负责连接和阅读节奏，不生成季度之间的新数据。核心交互“季度棱镜”像一个读数窗：选中季度后，数值、单位、实体范围、证据和来源同时出现。遇到 Lineage 的重叠季度，单条潮位带在窗口中分成旧口径与新口径两路；遇到推导值，则展开为带上下界的区间。事件只放在独立时间轨上，不画成指向收入变化的因果箭头。

整体使用暖纸色背景、深青与水绿色数据层、珊瑚色事件标记。大字号负责提出结论，图形负责展示变化，完整 Finding 与限制留在可展开的证据层。这样既保留作品的视觉张力，也让口径、版本和不确定性无法被轻易略过。
