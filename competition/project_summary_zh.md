# 项目简介

《付费潮汐——游戏商业生命线》研究上市游戏公司公开披露中的游戏、IP 与 franchise 商业轨迹。项目没有把不同公司的“收入”拼成一个全球排行榜，而是先辨认实体范围、财政季度、报告口径、证据类别与指标版本，再在同一稳定序列内观察变化。最终语料包含 4 家发行商、9 条分析序列、75 个季度观察、26 个精选官方事件和 3 条发行商归因说法；其中 18 个观察由官方总额与取整占比推导，并保留上下界与方向稳定性。

六个正式 Findings 揭示了三类容易被忽略的问题：同一季度会因报告口径不同而出现不同数值；平台上线与收入峰值可以同期出现，但不能据此推断因果；一次恢复之后仍可能再次回撤。项目也明确呈现 NIKKE 的观察窗口未恢复、Lineage W 新口径窗口的连续下降，以及取整占比使 60.0% 的派生环比方向不确定。

核心交互 Quarter Prism / 季度棱镜让使用者移动财政季度，同时查看数值、实体、口径、证据、区间、事件与来源。Tidal Ledger / 潮汐账本视觉系统以账页、校准刻度、版本接缝和独立事件轨表达研究边界。网站支持键盘、移动端步进与减少动态，并把来源链接放回每个观察附近。项目的价值不是给出一个看似统一的“真相数字”，而是让每个商业观察都能被追溯、被限定，也能被诚实地比较。
