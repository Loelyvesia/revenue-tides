# Quarter Prism / 季度棱镜

Quarter Prism turns one selected fiscal quarter into a complete analytical reading unit. A user chooses a publisher-defined series and moves with previous/next controls, a native quarter selector, direct quarter buttons, or Left/Right keyboard input.

## States

- **Direct observation:** shows the raw value, unit, entity scope, metric version, evidence class, transformation state, and source.
- **Version overlap:** shows legacy and royalty-integrated observations simultaneously in separate lanes. A calibration seam marks the definition break; no quarter is overwritten.
- **Derived uncertainty:** uses a diamond and interval geometry for the point estimate and compatible bounds, together with rounded-share and sign-stability notes.
- **Event context:** places official events on a separate copper rail. Issuer explanations remain labeled attributions.
- **Mobile:** becomes a stacked quarter stepper while preserving the same meanings and controls.

## Why this is not a tooltip

A normal tooltip is temporary, usually hover-dependent, and optimized for one point. It cannot safely carry simultaneous versions, bounds, non-causal event context, attribution, caveats, and source routes. Quarter Prism persists selection, supports keyboard and mobile input, announces changes through a live region, and makes each semantic layer visible without forcing the user to infer research rules from footnotes.

The interaction is analytically necessary because the project's central result is not merely how a value moves; it is how the meaning of that value is constructed.
